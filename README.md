Lanternfall — a spot-the-difference game at Pelican Quay: one hand-drawn night-harbour scene rendered twice, 10–12 differences per round across 3 escalating rounds, a last-ferry countdown, hints and a miss penalty. Built by an AI agent for make.fun's "Best spot-the-difference game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play: click a difference in either picture to ring it in both.
